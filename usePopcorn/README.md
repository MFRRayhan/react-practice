# 🍿 usePopcorn

A movie discovery and personal movie tracking application built with **React**. Search for movies, explore movie details, rate movies, and keep track of the films you've watched.


## 📸 About The Project

**usePopcorn** is a React-based movie application that allows users to search for movies using the OMDb API, explore movie information, and manage their personal watched movie list.

The project focuses on practicing React fundamentals, component-based architecture, state management, side effects, and working with external APIs.

## ✨ Features

- 🔍 **Movie Search:** Search for movies using the OMDb API.
- 🎬 **Movie Details:** Explore information about selected movies.
- ⭐ **Movie Rating:** Rate movies and manage personal ratings.
- 📋 **Watched Movies:** Keep track of movies you've watched.
- 📊 **Movie Statistics:** View a summary of your watched movies.
- ⚡ **Dynamic UI:** Interactive interface with responsive state updates.
- ⏳ **Loading States:** Display loading indicators while fetching data.
- 🚨 **Error Handling:** Handle API errors and unsuccessful requests.
- ⌨️ **Keyboard Support:** Interact with the application using keyboard shortcuts.

## ⚛️ React Concepts Practiced

This project helped strengthen my understanding of several React concepts:

- **useState:** Managing component state and user interactions.
- **useEffect:** Handling side effects and API requests.
- **useRef:** Accessing DOM elements and managing references.
- **useReducer:** Managing complex state transitions.
- **useCallback:** Optimizing callback references where needed.
- **Custom Hooks:** Reusing application logic.
- **Component Composition:** Building reusable and maintainable components.
- **Controlled Components:** Managing form inputs through React state.
- **Conditional Rendering:** Displaying UI based on application state.
- **Lifting State Up:** Sharing state between related components.
- **Data Fetching:** Fetching and handling external API data.
- **Event Handling:** Managing user interactions.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd usePopcorn
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL provided by Vite, usually:

```text
http://localhost:5173
```

## 🔑 API Reference

This project uses the **[OMDb API](https://www.omdbapi.com/)** to retrieve movie information.

You may need an API key to make requests. Get one from the OMDb website and configure it according to your project's API setup.
